# My Note-Taking System

A hybrid of **PARA** (folder structure + project lifecycle) and **Zettelkasten** (atomic, evergreen knowledge). PARA handles the *where*; ZK handles the *what endures*.

## The Flow

```
Inbox/ ──► triage ──► Projects/  (actionable, has deadline)
                  └──► Zettelkasten/Literature Notes/  (knowledge worth extracting)

Literature Notes/ ──► distill ──► Zettelkasten/Permanant Notes/  (timeless insight)

Projects/ ──► on close ──► Archive/ + key insights ──► Permanant Notes/
```

#### The habit loop to internalize:

1. **Capture** → Inbox (fast, no friction)
2. **File** → triage into Projects/ or Literature Notes within 24-48hrs
3. **Distill** → when something is worth keeping long-term, pull the insight into a Permanent Note
## Where Things Live

| Content                                     | Folder                           |
| ------------------------------------------- | -------------------------------- |
| Brain dumps, quick captures                 | `Inbox/`                         |
| Active project work, meeting notes          | `Projects/`                      |
| Ongoing responsibilities (no deadline)      | `Areas/`                         |
| Articles, vendor docs, source material      | `Zettelkasten/Literature Notes/` |
| Concepts and insights that outlive projects | `Zettelkasten/Permanant Notes/`  |
| Setup guides, templates, methodology        | `Resources/`                     |
| Inactive projects, closed work              | `Archive/`                       |

## Key Principles

- **Inbox is the fleeting layer** — no separate Fleeting Notes folder needed
- **Inbox discipline**: triage regularly; it should not be a permanent home
- **Projects vs ZK**: if it's *about* a project → `Projects/`. If it's a *concept that survives the project* → `Permanant Notes/`
- **Literature Notes** hold source + context; **Permanant Notes** hold your distilled understanding in your own words
- **Wikilinks** connect everything — a project note can link to a Permanent Note without moving it

## Delete vs Archive

> [!tip] The 6-month test
> *Would losing this note cause a problem in 6 months?* No → delete. Maybe → archive. Yes → it shouldn't be in Inbox anyway.

**Delete** when:
- The note has been fully processed into a better note
- It's a completed task reminder or duplicate
- It was wrong or superseded

**Archive** when:
- A project is closed but the context may matter later (audit trail, institutional memory)
- Meeting notes from finished initiatives
- Literature Notes already distilled — keep the source, the Permanent Note is the output
