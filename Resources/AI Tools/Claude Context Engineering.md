# 6 Key Elements for Context Engineering

1. Role
2. Goals & Audiences
3. Constraints (Styles/Formats)
4. Inputs
	- What is the data the LLM can use (i.e. use everything in the vault except ones with x tag)
5. Source of Truth
	- What kind of documents override the LLMs general knowledge or generic info
6. Judgement
	- How does the LLM judge what is good or bad
		- Frameworks = Tools that break down complexity (Analysis)
		- Creativity = Reassembly pieces into a new whole (Synthesis)
		- Mastery = Knowing when to use what frameworks
