Here's the process I follow (which is basically following the steps here at [Manual installation steps for older versions of WSL | Microsoft Learn](https://learn.microsoft.com/en-us/windows/wsl/install-manual "https://learn.microsoft.com/en-us/windows/wsl/install-manual") but doing them in a way that gets me the protect lilly pop-ups that I can actually authenticate with and not the ones blocked when running this stuff in powershell):

1. Start Menu -> "Turn Windows Features on or off" This will pop up a `protect lilly` authentication message (see screenshot 1) where you need to review what it says and click to authenticate through your browser.
2. In that turn on Virtual Machine Platform and Windows Subsystem for Linux and restart See screenshot 2
3. Install the WSL2 kernel for your x64 or arm based Windows 11 PC (step 4 in the microsoft link above). You have to do this with the .msi download. Other ways of doing this require privilege elevation as I'm sure you've probably run into: [https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi](https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi "https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi") or [https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_arm64.msi](https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_arm64.msi "https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_arm64.msi") Another source is microsoft's WSL2 github releases: [https://github.com/microsoft/WSL/releases#release-2.7.10](https://github.com/microsoft/WSL/releases#release-2.7.10 "https://github.com/microsoft/WSL/releases#release-2.7.10")
4. Then you can do step 6 here: [https://learn.microsoft.com/en-us/windows/wsl/install-manual#step-6---install-your-linux-distribution-of-choice](https://learn.microsoft.com/en-us/windows/wsl/install-manual#step-6---install-your-linux-distribution-of-choice "https://learn.microsoft.com/en-us/windows/wsl/install-manual#step-6---install-your-linux-distribution-of-choice") to pick your Linux installation of choice and install it from the Microsoft Store. I picked Ubuntu 22.04 (Jammy) since that matches the AWS PCluster and HPC Linux distros I am working from. [https://apps.microsoft.com/detail/9PN20MSR04DW](https://apps.microsoft.com/detail/9PN20MSR04DW "https://apps.microsoft.com/detail/9PN20MSR04DW") (make sure to click "View in Store" if this opens your browser instead of the Microsoft Store app). Then you setup your Windows Terminal to have an option pointing at that and can go from there.

  

This avoids needing to run elevated commands in powershell.
